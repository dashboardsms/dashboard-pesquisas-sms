# Dados

A fonte principal do dashboard será uma planilha Excel alimentada diariamente pela Escola.

## Campos de interesse identificados

Entre os campos observados no levantamento estão:

- Data de protocolo
- Número de protocolo
- Título da pesquisa
- Pesquisador responsável
- Orientador
- E-mail
- Instituição de Ensino Superior
- Programa
- Natureza da pesquisa
- Responsável pelo parecer
- Acompanhamento do processo
- Prazo de parecer
- Situação
- Declaração de anuência
- Parecer CEP
- Autorização de coleta de dados
- Período de coleta
- Previsão de entrega de relatório
- Distrito Sanitário
- Unidade de Saúde

## Observação

A base publicada no repositório, caso seja necessária, deverá ser uma versão modelo ou devidamente revisada para evitar exposição indevida de dados.
